    📚 توثيق API للمطورين (بدون تسجيل دخول — CORS مفتوح)
    MethodEndpointالوظيفة
    POST/api/jobsإنشاء مهمة دمج — {"videos":[...]} أو {"sources":[...]}
    POST/api/upload?job=&seq=&chunk=رفع أجزاء الملفات (ثنائي ≤4MB، octet-stream)
    POST/api/jobs/{id}/processتنفيذ الدمج كاملًا → رابط الفيديو النهائي (202 لو قيد المعالجة)
    GET/api/jobs/{id}الحالة + التقدم (0–100) + الرابط عند الاكتمال
    GET/api/jobs/{id}/videoبث الناتج بدعم Range — و?download=1 للتحميل
    DELETE/api/jobs/{id}حذف فوري شامل
    GET/api/configالحدود العامة + version
    GET/api/cronحذف المهام المنتهية (Cron يومي)
    curl -X POST https://DOMAIN/api/jobs -H "Content-Type: application/json" -d '{"videos":["https://example.com/a.mp4","https://example.com/b.mp4"]}'
# → {"jobId":"...","status":"queued","processUrl":"...","expiresAt":"..."}

curl -X POST https://DOMAIN/api/jobs/JOBID/process
# → {"status":"done","videoUrl":"https://DOMAIN/api/jobs/JOBID/video","size":...,"duration":...,"resolution":"1280x720"}
